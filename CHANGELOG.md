## Versioning

Once stable releases are established, Nexus intends to use:

`MAJOR.MINOR.PATCH`

### MAJOR

Breaking changes to documented public interfaces, APIs, architecture, data formats, or compatibility guarantees.

### MINOR

Backward-compatible features, APIs, integrations, and capabilities.

### PATCH

Backward-compatible bug fixes, security fixes, reliability improvements, and minor corrections.

## Pre-1.0 Development

Before `1.0.0`, Nexus is considered to be in active development.

APIs, architecture, configuration, and interfaces may change more frequently.

Significant breaking changes should still be documented clearly.
